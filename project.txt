SPESIFIKASI ARSITEKTUR & TEKNOLOGI:
--------------------------------------------------------------------------------
1. Frontend & Client-Side:
   - Framework : Next.js & Tailwind CSS
   - Deployment: Vercel Serverless (Custom Domain: tugas.searchstoree.com)
   - Fitur     : Google Auth, Dynamic Form Builder ala Google Forms, Responsive UI, Midtrans Popup.

2. Database & Storage:
   - Database     : PostgreSQL (Supabase)
   - Realtime     : Supabase Realtime Channels (Forum Diskusi & Pengumuman 2 Channel).

3. Autentikasi Admin & SMTP:
   - Sistem      : Whitelist Email di Database
   - Protokol    : SMTP Gmail untuk Aktivasi dan Reset Password Admin secara aman.

4. Payment Gateway:
   - Midtrans Snap: Multi-payment (QRIS, VA Bank, E-Wallet) dengan tombol verifikasi langsung.
