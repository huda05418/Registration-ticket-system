Proyek ini mengusung pendekatan Hybrid Architecture guna memastikan performa tinggi dan efisiensi sumber daya

1. Frontend & Client-Side
- Framework: Next.js & Tailwind CSS

2. Database & Storage
- Database: PostgreSQL
- Cloud Storage: Supabase Storage untuk penyimpanan berkas dan gambar poster.

3. Dedicated Runtime & Worker Service
- Runtime: Node.js
- Email Dispatcher: Nodemailer dengan protokol SMTP Gmail
- Ticket: Generator unik QR Code untuk validasi kehadiran di hari acara.

4. Payment Gateway:
- Midtrans: Menangani proses checkout dan settlement secara aman dan terenkripsi.
